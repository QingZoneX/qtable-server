### Planned `0.1.0-alpha` Open Source Preview

The `v0.1.0-alpha` version metadata and draft release notes are being prepared, but the release has **not** been published yet. The final version entry and release date must only be cut after the exact QTable/QTableUI revisions pass their real CI and full-stack release gates and the final open-source verification is complete.

### Included in the current release candidate

- multidimensional table backend with multiple views and advanced fields;
- workspace and row-level permission model;
- OAuth2 Authorization Code + S256 PKCE;
- Dashboard aggregation and permission-safe public sharing foundations;
- ChangeSet/audit and undo foundations;
- AI workspace generation, task planning, workload estimation, member assignment, project steward, action execution and AI visual design;
- QNote / Clipper Source Inbox;
- SQLite and PostgreSQL modes;
- Redis-backed optional AI/runtime capabilities;
- Alembic migration baseline;
- Docker Compose self-hosted stack;
- open-source governance and CI readiness gates.

### Alpha notice

Public APIs and migration details may change before v1.0. Production adopters should pin a released version and test upgrades in a staging environment.
